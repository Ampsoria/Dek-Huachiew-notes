### สรุปที่เราเขียนเอง ส่งต่อให้เพื่อนอ่านต่อ

เว็บรวมสรุป โน้ต และสไลด์ที่ผู้ใช้สร้างเอง ค้นหาตามรหัสวิชา หมวด GE คณะ และสาขา

**โปรเจกต์อิสระสำหรับชุมชนผู้เรียน ไม่ใช่เว็บไซต์ทางการของมหาวิทยาลัยหัวเฉียวเฉลิมพระเกียรติ**

[![ลองใช้ Mockup บน GitHub Pages](docs/assets/try-mockup.svg)](https://Ampsoria.github.io/Dek-Huachiew-notes/)

[คู่มือเปิดใช้จริง](docs/go-live.md) · [สารบัญรายวิชา](hcu-course-catalog.md) · [แผนโปรเจกต์](campus-notes-project-brief.md)

</div>

> **สถานะ:** GitHub Pages ใช้ดูหน้าตาเว็บและลองค้นหารายวิชาได้ หลังเปิด Pages และ workflow deploy สำเร็จ ฟีเจอร์บัญชี อัปโหลด Fav และรีวิวต้องเชื่อม Supabase ก่อน ปุ่มด้านบนจะเปิด URL ของ GitHub Pages; ถ้ายังไม่เปิด Pages จะยังเข้าเว็บไม่ได้

## ✨ ทำอะไรได้บ้าง

| ส่วน | สถานะ |
| --- | --- |
| สารบัญ GE → คณะ → สาขา → รายวิชา และค้นหาด้วยรหัส/ชื่อวิชา | ใช้ได้ใน mockup |
| หน้าอ่านวิชาและเลย์เอาต์ responsive สำหรับมือถือ, iPad และคอม | ใช้ได้ใน mockup |
| Google login, ตั้ง username/โปรไฟล์, พื้นที่ของฉัน, Fav | ต้องเชื่อม Supabase |
| อัปโหลด PDF/รูป, อ่านเอกสาร, รีวิว 1–5 ดาว | ต้องเชื่อม Supabase |
| คอมเมนต์แบบกระทู้, คุยรายหน้า และแชต | ยังไม่พัฒนา |

ข้อมูลตั้งต้นมี **890 รหัสวิชา** จาก [สารบัญ Moodle ที่รวบรวมไว้](hcu-course-catalog.md) ยังไม่ได้ตรวจรับรองกับหลักสูตรทางการ จึงควรตรวจชื่อวิชา รหัส คณะ และสาขาก่อนเปิดรับผู้ใช้จริง

## 🚀 ลองใช้ Mockup

กดปุ่มด้านบนเพื่อเปิด GitHub Pages หลังตั้งค่า **Settings → Pages → Source: GitHub Actions** และ workflow `Deploy to GitHub Pages` ทำงานสำเร็จ เว็บจะเผยแพร่ที่ `https://Ampsoria.github.io/Dek-Huachiew-notes/` โดยอัตโนมัติ

หากต้องการรันในเครื่อง:

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal โดยไม่ต้องสร้างไฟล์ `.env.local` ก็ลองสารบัญและค้นหาได้

## 🧱 เทคโนโลยี

React · TypeScript · Vite · Supabase (Auth, PostgreSQL, Storage) · GitHub Pages สำหรับ mockup

เมื่อเปิดใช้งานจริง สามารถใช้ GitHub Pages ต่อหรือ deploy frontend ไป Cloudflare Pages ตาม [คู่มือเปิดใช้จริง](docs/go-live.md) ได้ ระบบสมาชิกและข้อมูลยังต้องตั้งค่า Supabase ไม่ว่าเลือกโฮสต์ใด
